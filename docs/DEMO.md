终端一：

```powershell
conda activate LLM
python -m uvicorn data_copilot.api:app --reload
```

终端二：

```powershell
conda activate LLM
python -m streamlit run frontend/app.py
```

使用启动提示中的页面地址；后端文档默认为 <http://127.0.0.1:8000/docs>。提前准备 data/samples/sales.csv、evals/fixtures/zero_variance.csv，以及一份已有七案例评估/审核报告。不需要为演示重新运行整个评估集。点击分析会调用真实模型，产生相应费用。

## 约三分钟流程

| 时间参考 | 操作 | 讲解和通过条件 |
| --- | --- | --- |
| 0:00–0:20 | 展示页面与项目目标 | 用户自然语言提问；模型选择工具，Python 计算，模型解释 |

复合问题：

> 这份数据有多少行、多少列？每个地区的平均销售额是多少？请保留地区缺失组。

预期规模 40 行、6 列；地区均值如下，展示可舍入：

| region | mean |
| --- | ---: |
| East | 680.375 |
| West | 707.5 |
| North | 686.5 |
| South | 699.3333333333334 |
| 缺失地区 | 721.5 |

零方差问题：

> 请计算 x 与 y 的 Pearson 相关系数和有效样本量，解释无法计算是否表示相关系数为零。

当前 fixture 的 x 恒为 10，y 为 2、5、9。若模型只拿到 correlation 返回值，它只能断言至少一列零方差；只有其他工具提供依据时，才应具体说明哪列恒定。

## 错误提示补充核对

如果此前场景已经确认，不必为最终演示制造上游故障。需要复查时：

- 停止 FastAPI、保留 Streamlit，提交后应显示无法连接后端；重新启动后再继续分析。
- 上传空 CSV，通过 /docs 应返回 400；空白问题为 422，超过 5 MiB 为 413。
- 502/504 的后端异常已用离线测试验证，不需故意等待真实超时。
- Clash 开启、后端停服时，本机通信应仍显示连接失败；此项目仅绕过 HTTPX 环境代理，不修改 TUN 或后端模型网络设置。
